# Human baseline 최종본 (HB-FY24, 2026-10-19)

2026년 10월 19일 지도교수 미팅까지 검토를 마친 Human baseline 비교 자료의 최종본이다. 이후 Human baseline에 관한 수치와 서술은 이 폴더를 기준으로 한다.

이 폴더는 재현 키트 본체(`main`)와 별개이며, 이전 미팅 패키지(`hb-fy24-advisor-package` 브랜치)를 대체한다. 고정 시점은 태그 `hb-fy24-final-20261019`로 표시한다.

## 표본과 주요 수치

- 문서 236건(신용평가사 95건, 증권사 등 리서치 보고서 141건), 161개 기업. 수집 기간 2025.1.1~6.30.
- 행동 종류 비교 56개 기업, 점수 비교 53개 기업(문서 행동이 후보 하나에 정확히 대응하는 3개 기업은 별도 보고).
- 53개 기업 Oracle-α 정책가치: LLM 직접 권고(C4) GPT +0.857, Gemini +0.762 / RL 참조 LLM(C6-E) +0.820, +0.776 / Human baseline +0.638. 기업 단위 대응 차이의 95% 부트스트랩 구간은 모두 0을 포함한다.

## 원문

신용평가사 평가의견서와 리서치 보고서 원문은 저작권 문서이므로 이 저장소에 포함하지 않는다. 각 문서의 공식 링크는 `03_evidence_pack/01_출처목록_HumanBaseline.xlsx`에 있고, 원문 묶음은 비공개 저장소에 보관한다. 원문 묶음의 SHA-256 값은 `SHA256SUMS.txt`에 적어 두었다.

## 확인

```
sha256sum -c SHA256SUMS.txt --ignore-missing
```
