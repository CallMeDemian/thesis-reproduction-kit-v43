# 구조적 재검토 분석 스크립트 (2026-11-17)

재현 키트의 Simulator와 신용평가모형 코드를 그대로 불러 임의의 행동을 채점한다(재구현 없음).

## 준비
- `frozen/distribution/THESIS_REPRO_KIT_v2.1.1_FINAL.zip`을 풀고 그 폴더를 `KIT_ROOT` 환경변수로 지정한다. 코드는 zip 안의 `src`를 쓴다.
- ablation release의 `ablation_20261102/E1/observations/e1_observations.parquet` 경로를 `ABL_E1`로 지정한다.
- 패키지: numpy 2.3.3, pandas 2.3.3, scipy 1.16.1, scikit-learn 1.6.1, joblib, PyYAML, pyarrow, statsmodels. (이 조합에서 γ까지 동결 점수와 일치했다.)
- 모든 스크립트는 이 폴더를 작업 폴더로 두고 실행한다. 중간 산출물(.npy, .npz, .parquet)이 같은 폴더에 생긴다.

도전자 평가모형 δ·ε은 이번 분석에서 새로 만든 것이다. 적합 규칙(개발 기간 적합, 1~99% 윈저화, 중앙값 대체, Ridge와 HistGradientBoosting)은 정책 결과를 보기 전에 정했고 조정하지 않았다. ε은 δ 결과를 본 뒤에 추가했다.

강화학습 정책의 보상은 키트 코드(`src/credit_recourse/rl/v43_reward_components.py`, `v43_reward_math.py`)에서 확인했다: 실제 등급 변화와 세 보조 항목(부도거리 대용변수, 현금흐름, 유동성)의 합이며, 평가모형 점수와 평가모형 변수는 보상 경로에서 금지돼 있다.
