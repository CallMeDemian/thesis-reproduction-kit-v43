## 결론

기존 연구의 확정 가능한 기여와 E1의 해석 범위, 비용축 분석의 비인과적 성격을 분리해 기록했고 연구설계서 v4와 Gate 1 프로토콜 초안을 작성했다. GitHub의 frozen-evidence 기본 재현은 PASS했고 R1·R7·R9의 코드 재실행도 묶음 출력과 일치했다. 누락된 11월 17일 분석 코드 때문에 R2–R6·R8은 재현 불가이며, Simulator 원입력이 없어 B1도 실행하지 못했다.

따라서 이번 1차 관문에서 중단한다. 새 API 호출, E2 pilot, 본실험, RL 재학습 및 원격 Git 쓰기는 수행하지 않았다. E2_PROTOCOL.md 해시는 설계본을 식별하기 위한 것이며 실행이 승인되었다는 뜻이 아니다.

## 핵심 연구 질문에 대한 Gate 1 답변

### 1. 기존 연구에서 이미 입증된 기술적 기여는 무엇인가?

[기록] 제한적인 관측 신용등급 변동 감독정보와 Simulator 보상을 사용해 기업별 8축 행동을 학습한 RL 참조정책 C3-E를 만들고, 그 기업별 행동을 LLM 입력에 제공했다. E1은 고정 OE 행동 참조와 비교해 RL 행동 참조에 추가 정보가 있는지 탐색했다. release 기록상 α 차이는 GPT +0.156, Gemini +0.145였고 β는 각각 −0.022, −0.018이었다. 이 결과는 frozen Simulator/Oracle 정책가치 차이다. 실제 실행 결과가 아니고, α가 C3-E 선택에 사용되었으며, 같은 575개 기업을 재사용했다.

### 2. 구성·배정 분해로 새롭게 확인된 현상은 무엇인가?

이번 실행으로 구성·배정 가치 분해를 다시 계산하지 못했다. 기업×행동 전체 쌍의 점수표와 Simulator 입력이 없기 때문이다. 따라서 v3에 기록된 C3-E 배정가치 등의 수치를 새로 확인한 결과로 말하지 않는다.

현재 코드 재실행에서 확인한 별도 현상은 RL 참조가 있는 C6-E의 exact action agreement가 C4R보다 GPT +8.2%p, Gemini +4.3%p 높았고 두 모델 간 일치도 +8.7%p 높았다는 것이다. e33/e34에서는 비용축 권고의 대다수가 매출원가율·판관비율을 균형 배분했고, 그 비중과 점수 사이의 기업 내 연관이 관찰됐다. 이는 출력 일관성과 관찰 패턴이다. 배정의 원인이나 매출원가율을 조정했을 때의 인과 개선은 아니다.

### 3. RL 참조와 평가모형 기반 행동 선택의 차이는 무엇인가?

RL 참조는 이전에 학습된 C3-E의 기업별 행동 vector를 보여 주며 생성 시 점수·가중치·행동 순위를 직접 주지 않는다. 평가모형 기반 행동 선택은 여러 생성 후보를 평가모형 점수나 순위에 따라 고른다. 따라서 정보의 출처와 선택 절차가 다르다. 다만 RL 정책 선택 자체는 α에 의존했고, Simulator 결과표는 평가모형 입력 proxy를 제공할 수 있다. R3–R6의 격차 수치는 재현되지 않아 이번 Gate에서 일반적 강건성 결론을 새로 추가하지 않는다.

### 4. E2가 기존 연구에 실제로 추가할 수 있는 기술적 기여는 무엇인가?

[가설] 같은 기업·같은 초안 조건에서 Simulator 재무결과표를 RL 참조에 추가하면 α 정책가치가 더 높은지, 변화가 행동 구성·기업별 연결 중 어디에 나타나는지, 모델의 결과 예측 정확도와 관계가 있는지 검증할 수 있다. 긍정 결과가 있더라도 “Simulator 정보가 frozen Oracle 환경에서 LLM 권고를 개선했다” 수준의 기여다. 기업의 실제 성과 개선이나 평가정보 독립성을 증명하지 않는다.

### 5. 학위논문 제출 전에 E2가 필요한가?

[판단] 현재로서는 필요하지 않으며 후속 연구로 두는 편이 낫다. 기존 RL 참조와 E1 탐색 결과의 기술적 기여는 claim을 정확히 고치고 trade-off·선택 의존·외적 타당도 한계를 적어 설명할 수 있다. E2는 본실험 12,650건 외에 1,200건 pilot이 계획되어 총 13,850 logical requests이며, B1 Simulator 자료와 C2/프롬프트 교차검증도 아직 해결되지 않았다. 신규 효과의 크기와 API 비용은 확인되지 않았다. 11월 30일 미팅에서는 v4와 재현 보고를 바탕으로 기존 논리·한계를 먼저 정리하고, 12월 2일 초안은 확인된 기존 결과로 작성하는 것이 일정·연구신규성·작성 부담 측면에서 합리적이다.
