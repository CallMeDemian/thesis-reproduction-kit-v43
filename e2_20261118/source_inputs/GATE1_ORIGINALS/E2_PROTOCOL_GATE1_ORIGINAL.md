# E2_PROTOCOL

## 문서 상태

고정일: 2026-11-18  
분석 결과 열람 전 설계 해시용 Gate 1 protocol. E2 요청을 실행한 적은 없다.  
실행 상태: HOLD — 본 문서는 통계·조건·해석 규칙을 고정하지만, 아래 실행 전 차단항목이 채워지지 않아 실행 준비가 끝난 프로토콜은 아니다. 본실험·파일럿·유료 API 사용 승인을 뜻하지 않는다.

## 1. 연구 질문과 추정 대상

연구 질문: 학습된 C3-E 행동 참조와 동일한 Simulator 결과표를 함께 제공하면, C3-E 참조만 제공하는 경우보다 LLM이 만든 8축 행동의 α 정책가치가 높아지는가?

정책가치는 2024 회계연도 575개 기업의 동결 재무정보, Simulator, Oracle α로 평가하는 점수 차이다. 실제 기업이 권고를 실행한 뒤 관측한 성과가 아니다.

## 2. 표본·모델·반복

- 표본: GitHub canonical ITT observations에 명시된 575개 firm_key. E2 원요청 전에 입력 파일의 SHA-256과 전체 firm_key 정렬 목록의 SHA-256을 기록한다.
- 기업·표본·회계연도는 기존 2024년 자료와 동일한지 request manifest와 대조한다. 다른 기업 또는 기간은 대체하지 않는다.
- 모델: E1에서 사용한 GPT-5.4-mini와 Gemini 3.1 Flash-Lite. 실제 provider model ID, 날짜 버전, 파라미터는 E1 request manifest와 호출 가능성 검증으로 고정해야 한다. alias만으로 실행하지 않는다.
- 생성: 추론 높음, 자유작성 8축, IC-b, B1 행동예산, 엄격 규칙. E1의 두 실행 설정·기본 프롬프트·출력 schema를 그대로 따른다.
- 반복 1은 해당 기업의 1차 초안, 반복 2는 별도 생성한 해당 기업의 2차 초안에서 각각 갈라진다. 같은 기업·모델·반복에서 모든 조건은 동일한 초안 해시를 사용한다.
- 기업별 원 프롬프트, 입력 payload, 출력 schema, 참조 vector, model ID, generation parameters를 보존하고 SHA-256으로 manifest에 고정한다.

## 3. 실험 조건

| 조건 | 행동 참조 | 결과표 |
|---|---|---|
| E2-N | 없음 | 없음 |
| E2-R | 검증된 C3-E 기업별 행동 | 없음 |
| E2-T | 없음 | 공통 10행 |
| E2-RT | E2-R과 byte-identical | E2-T와 byte-identical |
| E2-B | 검증된 behavior-cloning 정책의 기업별 행동 | 없음 |
| E2-Q | 재검토 지시 없음; 행동별 결과 예측 질문 | 없음 |

각 수정조건은 동일한 초안에서 별도 생성하고 이전 응답을 넘기지 않는다. E2-R과 E2-RT는 참조 JSON과 문구가 완전히 같고 출처를 밝히지 않는다. E2-N/T에는 참조 유무·정체를 언급하지 않는다. E2-B도 E2-R과 같은 참조 형식을 사용하며 정책 출처를 숨긴다.

조건별 요청 수는 E2-N/R/T/RT/B: 5 × 575 × 2 모델 × 2 반복 = 11,500건, E2-Q: 575 × 2 모델 = 1,150건이다. 전체 본실험은 12,650건이다. 별도의 100개 기업 pilot은 1회씩 1,200건이며 본실험에 재사용하지 않는다. Pilot과 main E2는 Gate 1 이후 별도 승인 전까지 실행하지 않는다.

## 4. 행동 계약과 결과표

### 4.1 행동 계약

v43_action_contract.json의 8개 축, 범위, 표준행동, 부호 및 단위를 그대로 쓴다. 정규화 척도:

| 축 | 1 normalized unit에 대응하는 원 단위 |
|---|---:|
| growth_capex_reduction_pct | 0.6310184441953189 |
| deleveraging_total_debt_pct | 0.3469549324277901 |
| refinancing_short_debt_pct | 0.4741061962838509 |
| inv_turnover_chg | 1.398376123199908 |
| ar_turnover_chg | 0.9341039044455588 |
| ap_turnover_chg | 2.4535741981135732 |
| cogs_ratio_chg | 0.026882606612335436 |
| sga_ratio_chg | 0.01716946739071251 |

행동 크기 T는 정규화된 절대 축 값의 합이며 B1에서 T≤1이어야 한다. 요청 당시 원 프롬프트에 기재된 행동예산 정의를 대조하고 다른 정의가 있으면 실행하지 않는다. 1단위 단일축 표 행과 초안 행동은 각 행을 따로 계약 검사한다. 행동 합산은 허용하지 않는다.

### 4.2 10행 결과표

각 기업·반복마다 다음 10개를 무행동 기준으로 따로 시뮬레이션한다.

1. A0 무행동
2. 해당 기업·반복의 LLM 초안 행동
3–10. 위 표의 8개 축에 각기 단일 1 normalized unit만 적용한 행동

예정 재무변화 열: 매출액, 영업이익, 세전이익, 이자비용, 총차입금, 단기차입금, 현금및현금성자산, 유동자산, 유동부채, 자본총계, 영업활동현금흐름.

결과표 도입 문구는 다음 문장으로 고정한다: “아래 표는 회계 Simulator가 계산한 각 행동의 1년 뒤 재무제표 항목 변화(무행동 대비)이며, 신용점수·등급·권고 순위는 포함되어 있지 않다. 여러 행동을 함께 하면 효과가 단순히 더해지지 않을 수 있다.” 통화·단위 등 필요한 정보는 두 조건에 동일하게 별도 표 머리글에서 명시한다.

변화량은 반드시 동일한 회계연도·기초 기업 재무상태·Simulator 버전에서 생성한다. 표의 금액 단위(원/천원/백만원 등), 부호, 기간, 반올림 자릿수 및 missing·실행불가 표시는 실제 Simulator 출력 schema와 대조해 기록한다. 해당 계약이 없으면 표를 생성하지 않는다.

각 행은 개별 행동 시뮬레이션이다. 행별 변화량을 더해 복합 행동 결과로 읽을 수 없다는 문구를 함께 제공한다. 점수, 등급, 평가모형 가중치, 평가변수 명칭 및 후보 행동 순위는 표와 프롬프트에 넣지 않는다. 효과 0과 실행불가는 별도 표기로 분리한다.

### 4.3 직접·간접 평가정보

직접 미제공 항목: α·β·γ 또는 δ·ε 점수, 신용등급, 평가모형 가중치, 후보 순위.

간접 전달 가능성: 금액 변화량은 재무 상태 변수이며, 기초 재무정보와 함께 제공될 경우 이익률·레버리지·이자부담·유동성·현금흐름 관련 평가변수를 계산하는 데 도움을 줄 수 있다. 따라서 결과표가 Oracle 입력정보와 독립이거나 평가모형 정보가 완전히 차단되었다고 가정하지 않는다. ORACLE_SEAM_AUDIT.md에서 변수별 입력·비율 관계를 감사하고, Oracle 원 변수·산식이 확인되지 않으면 그 미확인 상태를 유지한다.

## 5. E2-Q 예측 과제

E2-Q는 재무 Simulator의 결과를 LLM이 얼마나 정확히 예측하는지 측정한다. 행동 입력은 해당 기업 초안 행동과 8개 단일축 1단위 행동이다. 질문 대상은 세전이익, 이자비용, 총차입금, 현금및현금성자산, 유동부채다.

기록할 지표: 변화 방향 오답률, 방향은 맞으나 변화율 배수 오차가 2배 초과한 비율, Simulator 변화가 없는 항목을 변화 있다고 한 비율.

아래가 고정될 때까지 E2-Q 실행을 막는다: 각 재무항목의 원 단위와 기초값 부호, 변화율 분모, 분모 0·근접 0 처리, “변화 없음” 임계값, Simulator 변화 0 판정 tolerance. E2-Q는 보조 설명 분석이며 H1의 대체 지표가 아니다.

## 6. 가설과 결과 보고

| 가설 | 추정 대비 | 역할 |
|---|---|---|
| H1 | E2-RT − E2-R, α 정책가치 | 주 가설 |
| H2 | H1 대비의 구성 가치와 배정 가치 | 보조 |
| H3 | E2-RT − C3-E, E2-RT − 고정 COGS 1단위 감소 | 보조 |
| H4 | E2-R − E2-B 및 E2-B − E2-N | 보조; C2/BC 정책 교차검증 전 실행 금지 |
| H5 | E2-RT − E2-R − E2-T + E2-N | 보조 상호작용 |
| H6 | E2-Q 예측 오류 | 보조 |

- H1 기본 estimand: 기업별로 두 모델×두 반복의 E2-RT−E2-R α 차이를 평균한 뒤, 575개 기업의 평균 차이를 추정한다.
- 결합 H1은 단 하나의 95% CI를 주 판정으로 사용한다. CI 하한이 0보다 크면 지지, 그 외에는 불확실/지지되지 않음으로 기록한다. 유의하지 않다는 이유로 동등·무손실·효과 없음이라고 판정하지 않는다.
- 모델별 estimand: 각 모델의 두 반복 평균 차이, 95% CI, paired 기업별 값 및 Holm-adjusted p 값을 보고한다. 결합 평균이 양수여도 모델별 추정·CI가 각각 지지하지 않으면 “두 모델 모두 개선”이라고 주장하지 않는다.
- α와 함께 β·γ의 동일 대비, 효과크기 및 95% CI를 보고한다. 악화된 지표를 포함한다.
- 기업 단위 paired cluster bootstrap: 10,000회, percentile 95% CI, NumPy PCG64, seed 20261118. 한 기업을 뽑을 때 해당 기업의 모든 조건·모델·반복을 함께 뽑는다. 재표집 인덱스를 대비 및 지표에서 공유한다.
- Wilcoxon signed-rank는 사전 정의한 보조 결과로만 보고한다.
- H2–H6은 보조 분석이며 결과를 본 뒤 주 가설로 격상하지 않는다. H3·H4의 복수 대비는 각 family에서 Holm 보정 결과를 함께 제시한다. H5는 추가 상호작용 해석이며 연구의 성공 여부를 단독으로 정하지 않는다.
- 기업·조건·실행별 값을 보존한다. α 한 개만 선택하여 보고하지 않는다. 분석 코드, 패키지 잠금파일, protocol SHA-256, 출력 스키마를 실행 전에 봉인한다.

## 7. 구성·배정 가치 계산

기업별 10행과 생성 행동을 같은 Simulator/Oracle로 점수화한 뒤 V, C, A를 계산한다.

V = 평균ᵢ S(i,aᵢ)  
C = 1/[N(N−1)] × Σᵢ≠ⱼ S(i,aⱼ)  
A = V−C

우선 모든 ordered firm-action pair를 계산한다. 실행불가 행동 처리·교차기업 재배정의 유효성·missing 표기는 원 Simulator 규칙을 따른다. 전체 쌍 계산이 불가능하면 결과를 임의 대체하지 않고 규모, 고정 순열, 시드와 그 한계를 protocol amendment로 결과 보기 전에 고정한다. 고정 정책에 대해 A≈0인지 단위 검사한다. 모든 조건에 같은 방식 적용한다.

현재 R8에 필요한 full Simulator surface와 E2 결과표 생성 자료가 없으므로 이 절은 분석 계획이며 계산 결과가 아니다.

## 8. B0·B1 실행 차단표

| 선행 항목 | 실행 전 검증 |
|---|---|
| 원 프롬프트·E1 참조 | E1 전체 prompt·reference payload·model ID를 GitHub release request manifest에서 추출하고 SHA-256 저장 |
| 기업 자료 | 575개 firm_key, 회계연도, 기초 재무상태 원자료 해시와 기존 canonical 표본 대조 |
| Simulator | executable/version, input/output schema, 금액 단위, 시점, missing·불가 행동 규칙 |
| 회계 | 자산=부채+자본 등 적용 항등식 및 Simulator 단계별 수지 검사 |
| 행동 | 축별 부호·범위, T≤1, 동시제약, 실행 가능성, zero effect와 불가 분리 |
| Oracle seam | α·β·γ의 실제 기초변수·산식과 11개 table columns의 입력 또는 계산 가능 관계 |
| E2-B | 행동모방 정책 ID, C2 crosswalk, 575개 기업별 행동벡터와 분포 검증 |
| E2-Q | 단위·부호·변화율 분모·zero tolerance·효과없음 임계값 |
| 실행 | 모델 ID/version, 비용 추정, rate limit, 재시도 한도, prompt/output SHA, 샘플링·부트스트랩 구현 |

B1 고정 정책 정의(모두 탐색 진단):

| 정책 | 정의 |
|---|---|
| P0 | 검증된 C3-E 기업별 행동 |
| P1 | Heuristic 고정 OE |
| P2 | 매출원가율만 계약상 1단위 감소한 고정 행동 |
| P3 | C3-E 행동. OE 선택 기업은 P2 행동으로 대체 |
| P4 | C3-E 행동 0.5배 + 매출원가율 0.5단위. OE 선택 기업은 P2 |

각 정책은 v43_action_contract.json의 범위·부호·실행가능성·행동예산을 통과해야 한다. P3/P4/P5가 낮아도 본 실험 가설을 고치지 않는다. 교란 조건(+1%p 장기 전환분 가산금리, 비용절감 실현율 50%)은 e15–e26의 실제 구현과 동일 입력이 확보될 때에만 탐색적으로 계산한다. 없는 구현을 추측하지 않는다.

## 9. 결과열람 방화벽과 중단 조건

- Oracle 점수, 신용등급, 가중치, 점수 기반 행동순위를 prompt·table에서 금지한다.
- E2 결과표·prompt·조건·가설·통계 기준은 본실험 점수를 본 후 수정하지 않는다.
- 오류·누락·조건 오염은 그대로 기록하고 임의 복구하지 않는다.
- E2 pilot과 본실험은 이번 Gate 1 작업 범위 밖이다. 별도 승인이 있기 전 신규 유료 API 호출, 100기업 pilot, 본실험, RL 재학습을 하지 않는다.
- Frozen data·논문·발표 원본을 수정하지 않는다.
- 매출원가율/판관비율의 배분을 바꾸는 반사실 Simulator 분석이 수행되면 e33/e34 결과와 다른 분석으로 별도 표시한다.
