| E2-B | 행동모방 정책의 행동 | 없음 | 참조의 학습 단계 비교 |
| E2-Q | (수정 아님) 결과 예측 질문, 1회 | 없음 | LLM의 결과 예측 정확도 |

- 다섯 수정 조건은 같은 기업·모델·실행의 같은 초안에서 따로 갈라 보낸다. 1차 실행은 1차 초안, 2차 실행은 2차 초안을 쓴다. 조건 사이에 결과를 이어받지 않는다.
- E2-R과 E2-RT의 참조 내용·문구는 완전히 같다. E2-N과 E2-T에는 참조에 관한 어떤 정보도 주지 않는다.
- E2-N·E2-R의 프롬프트는 본실험의 C4R·C6-E와 같다.
- E2-B의 참조 제시 형식은 E2-R과 같다. 참조의 출처는 어느 조건에서도 밝히지 않는다.
- 요청 수: 수정 5개 조건 × 575 × 2개 모델 × 2회 = 11,500건, E2-Q 575 × 2 = 1,150건. 합계 12,650건. 시범은 별도 1,200건.

### 4.2 결과표

- 행은 정확히 10개: 무행동, 그 실행의 초안, 8개 축 각각의 단일 1단위 행동. E2-T와 E2-RT에 같은 행, 같은 열, 같은 순서, 같은 자릿수로 준다. 참조 행동의 행은 따로 넣지 않는다.
- 1단위는 행동 계약의 축별 척도 1배이고, 방향은 표준행동에서 쓰는 부호다.
- 열: Simulator가 계산한 1년 뒤 재무제표 금액 항목의 무행동 대비 변화. 매출액, 영업이익, 세전이익, 이자비용, 총차입금, 단기차입금, 현금및현금성자산, 유동자산, 유동부채, 자본총계, 영업활동현금흐름.
- 비율, 평가모형 점수, 등급, 평가모형 변수 이름, 행동 순위는 넣지 않는다.
- 각 행은 무행동에서 따로 한 번씩 계산한다. 축별 효과를 더해 혼합 행동의 효과로 보이지 않는다.
- 효과가 없는 행동(변화가 모두 0)과 실행할 수 없는 행동은 구별되는 고정 서식으로 표시한다. 실행 불가 사유는 내부 기록에 남긴다.
- 프롬프트에 더하는 글은 다음 두 문장뿐이다. 무행동을 가리키는 낱말은 기존 프롬프트의 것을 쓴다.
  - "아래 표는 회계 Simulator가 계산한 각 행동의 1년 뒤 재무제표 항목 변화(무행동 대비)이며, 신용점수·등급·권고 순위는 포함되어 있지 않다. 여러 행동을 함께 하면 효과가 단순히 더해지지 않을 수 있다."
- 특정 행동을 고르라는 지시를 넣지 않는다.
- 결과표의 열과 α·β·γ의 9개 변수의 관계(그 변수의 구성 항목인지)를 `ORACLE_SEAM_AUDIT.md`에 표로 남긴다.

### 4.3 E2-Q (결과 예측)

- 입력: 초안과 같은 기업 정보, 행동 9개(그 기업의 1차 초안, 8개 축 단일 1단위).
- 질문: 각 행동을 하면 1년 뒤 세전이익, 이자비용, 총차입금, 현금및현금성자산, 유동부채가 무행동 대비 늘어나는지, 줄어드는지, 그대로인지와 대략의 변화율.
- 채점: 같은 기업·같은 행동의 Simulator 값과 대조한다. 방향 오류율, 크기 오류율(방향은 맞고 변화율이 2배 넘게 다름), 효과가 없는 행동을 효과가 있다고 답한 비율.
- "그대로"의 범위(변화율 절댓값 0.1% 미만)와 분모가 0에 가까울 때의 처리는 실행 전에 고정한다.
- 이 값은 설명용이다. 결과표의 효과를 증명하는 근거로 쓰지 않는다.

### 4.4 가설과 판정 (실행 전 고정)

| 번호 | 내용 | 지표 |
| --- | --- | --- |
| H1 (주 가설) | 참조 + 결과표 수정은 참조만 준 수정보다 정책가치가 높다 | E2-RT − E2-R, α |
| H2 | 그 차이가 구성 가치와 배정 가치 중 어디서 나오는가 | 구성 가치·배정 가치 각각의 E2-RT − E2-R |
| H3 | 강화학습 정책 단독, 고정 매출원가율 인하보다 높은가 | E2-RT − C3-E, E2-RT − 매출원가율만 1단위 |
| H4 | 강화학습 참조가 행동모방 참조보다 높은가 | E2-R − E2-B, E2-B − E2-N |
| H5 | 두 정보의 효과가 따로 준 효과의 합보다 큰가 | E2-RT − E2-R − E2-T + E2-N |
| H6 | LLM의 결과 예측이 얼마나 틀리는가 | E2-Q 오류율 |

- 주 지표: α 정책가치(무행동 대비), 엄격 규칙, 규칙 위반은 무행동 처리.
- H1의 판정: 기업마다 두 모델·두 실행의 E2-RT − E2-R을 평균한다(기업당 값 하나). 575개 평균의 95% 신뢰구간이 0보다 크면 지지로 적는다. 모델별 값은 함께 보고하고 두 모델에 Holm 보정을 한다.
- H2~H6은 보조다. 값과 신뢰구간을 그대로 보고한다. 유의하지 않은 감소를 "유지"로 적지 않는다.
- β·γ는 모든 대비에 함께 보고한다. 유의하게 낮은 평가모형이 있으면 그대로 적는다.
- 합성 지표(α·β·γ 차이를 평가모형별 표준편차로 나눈 평균)는 보조다. 표준편차는 본실험 동결 관측값(같은 조건, 모델별)에서 미리 계산해 `E2_PROTOCOL.md`에 고정한다.
- 결과를 본 뒤 가설, 지표, 기준을 바꾸지 않는다. 추가 분석은 "탐색적"으로 따로 적는다.

### 4.5 구성 가치와 배정 가치

정책 π가 기업 i에 준 행동을 a_i라 하고, S(i, a)를 기업 i가 행동 a를 했을 때의 무행동 대비 점수 변화라 한다.

```
정책가치 V = (1/N) Σ_i S(i, a_i)
구성 가치 C = (1/(N(N−1))) Σ_{i≠j} S(i, a_j)
배정 가치 A = V − C
```

- 구성 가치는 그 정책이 만든 행동들을 기업과 무관하게 나눠 줬을 때의 평균이다. 배정 가치는 기업과 행동의 연결에서 나온 몫이다. 값의 분해이며 원인의 증명이 아니다.
- 모든 (i, j) 쌍을 채점해 정확히 계산한다. 같은 행동은 한 번만 계산한다. 계산량이 과하면 모든 조건에 같은 고정 순열 100개를 쓰고 그 사실을 적는다.
- 실행별로 계산한 뒤 평균한다.
- 다른 기업의 행동을 받았을 때 실행할 수 없으면 기존 실행 규칙대로 처리하고 그 비율을 보고한다.
- 단위 시험: 모든 기업에 같은 행동을 주는 정책의 배정 가치는 0이어야 한다.

### 4.6 통계

- 기업 단위 부트스트랩 95% 신뢰구간. 기업을 다시 뽑을 때 그 기업의 모든 조건·실행·평가모형 값을 함께 옮긴다. 횟수와 시드는 논문의 방법을 따르고 `E2_PROTOCOL.md`에 적는다.
- 구성·배정의 신뢰구간은 다시 뽑은 기업 집합 안에서 4.5절의 식을 다시 계산한다.
- Wilcoxon 부호순위 검정은 보조로 함께 낸다.
- Holm 보정의 묶음: H1의 모델별 2개, 보조 대비(H3·H4)의 대비 × 모델.

### 4.7 순서

**B0. 프로토콜 고정**
- `E2_PROTOCOL.md`에 4.1~4.6절의 내용, 프롬프트 원문, 결과표의 열·단위·자릿수·표시 규칙, 요청 행렬, 통계 방법을 적고 해시를 기록한다. B1 전에 고정한다.

**B1. 계산 진단 (LLM 호출 없음, 탐색적)**
- 575개 기업의 결과표 10행을 만들어 저장하고, 회계 항등식·단위·부호·척도·제약을 검사한다.
- 아래 정책을 α·β·γ로 채점하고 구성 가치·배정 가치를 계산한다.

| 정책 | 정의 |
| --- | --- |
| P0 | 강화학습 정책 C3-E |
| P1 | Heuristic(고정 OE) |
| P2 | 매출원가율만 1단위 인하(고정) |
| P3 | C3-E. 단, C3-E가 OE를 고른 기업은 매출원가율만 1단위 인하 |
| P4 | C3-E 행동 0.5배 + 매출원가율 0.5단위. C3-E가 OE인 기업은 매출원가율만 1단위. 제약 위반 여부를 따로 검사 |
| P5 | 후보(C3-E 행동, 8개 축 단일 1단위, P4의 행동) 가운데 (세전이익 변화 + 현금및현금성자산 변화) ÷ 기초 총자산이 가장 큰 것. 동률이면 C3-E 행동 |

- 교란 조건(장기 전환분 가산금리 1%p, 비용 절감 실현율 50%)에서도 채점한다. 11/17 묶음의 구현을 쓴다. 없으면 구현 방식을 보고하고 승인받는다.
- 이 결과는 진단이다. P3~P5가 C3-E보다 낮아도 연구를 중단하지 않는다. 이 결과로 프롬프트, 결과표, 조건을 바꾸지 않는다.

**B2. 시범 (100개 기업, 품질 확인만)**
- 시드를 고정해 575개에서 100개를 뽑는다. C3-E 행동 종류의 비율을 맞춘다. 기업 목록과 해시를 남긴다.
- 6개 조건을 1회 실행한다(100 × 2개 모델 × 6 = 1,200건).
- 확인할 것: 프롬프트의 바이트와 해시, E2-T와 E2-RT의 결과표가 완전히 같은지, 같은 초안에서 갈라졌는지, 8축 출력의 해석, 규칙 준수율(본실험은 97~99%), 평가모형 점수·등급·변수 이름이 프롬프트에 없는지(문자열 검색), 응답이 잘렸는지, 참조 출처가 드러났는지, E2-Q 정답 계산. 원문 10건은 직접 읽는다.
- 시범 응답은 채점하지 않는다. 평가모형 점수를 계산하지 않는다.
- 품질 문제로 프롬프트나 결과표를 고쳤으면 `E2_PROTOCOL.md`를 다시 고정하고 시범을 다시 실행한다.

**B3. 본 실행**
- 575개 × 2개 모델 × 5개 조건 × 2회, E2-Q 1회. 시범 100개 기업도 새로 실행하고 시범 응답과 섞지 않는다.
- 규칙 위반, 해석 불가는 기존 엄격 규칙대로 무행동 처리한다. 고쳐서 살리지 않는다.
- 제안된 행동, 무행동 처리 뒤의 행동, 각 점수를 따로 보존한다. 논리 요청 수와 재시도를 포함한 실제 호출 수를 나눠 센다.
- 실행 도중에 유의성을 확인해 조건을 더하거나 표본을 고르지 않는다.

## 7. 이 설계에 넣지 않은 것

- 평가모형 점수를 보여 주는 수정 조건, 축 선택과 크기 배분을 나눈 출력 형식, 상위 모델, 유사 사례 검색 참조. 필요하면 별도 설계로 한다.

## 8. v1·v2에서 바뀐 점

| 항목 | v1 | v2 | v3 |
| --- | --- | --- | --- |
| 주장의 근거 | E2의 성공 | E2의 성공(특히 상호작용) | 작업 A의 재현 결과. E2는 확장 |
| 결과표 | 참조 조건에 한 행 더 | 모든 조건에 같은 10행 | v2와 같음 |
| 배정·구성의 역할 | 미리 정함 | 결과로 확인 | v2와 같음 |
| 1단계 결과로 중단 | 중단 | 중단하지 않음 | v2와 같음 |
| 고정 매출원가율과 비교 | 참고선 | 보조 가설 | v2와 같음 |
| 상호작용 | 표 하나 | 차별성의 핵심 근거 | 보조 가설(H5) |
| 주 가설의 판정 | 합성 지표 | α, 두 모델 모두 유의 | α, 두 모델·두 실행 평균으로 한 번. 모델별 값 병기 |
| 시범 | 점수 확인 | 점수 비공개, 열람 시 475개로 축소 | 채점하지 않음. 575개 유지 |
| 관문 | 3번 | 4번 | 2번 + 최종 |
| 구조화 출력(POGA) | 없음 | 별도 확장으로 제안 | 넣지 않음 |
| 도전자 평가모형 재적합 | 없음 | 없음 | 작업 A에 포함 |
| 구성 가치 계산 | 20회 섞기 | 100개 고정 순열 | 모든 쌍의 정확 계산 |
